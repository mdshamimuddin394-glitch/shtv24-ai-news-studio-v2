# SHTV24 - AI News Studio

AI-powered Bangla news automation - Made in Sylhet, Bangladesh

## What is SHTV24?

I am the solo founder of SHTV24. As a journalist from Sylhet, I built this myself.

SHTV24 turns any news topic into a Bangla news script, AI anchor voice, and live studio experience.

## What I Built

- Frontend: HTML, CSS, JavaScript - AI Bangla News Anchor UI
- AI: Nebius AI Studio - Llama 4 Maverick 400B for Bangla translation and news script generation
- Voice: AI Text-to-Speech for Bangla news reading
- Studio: Live Studio Mode with Sylheti Bangla support

## Features

- AI Bangla News Script Generator
- AI Voice Anchor
- Live Studio Mode
- Truth News - Satto Khobor
- Sylheti Bangla Prompts

## How to Run

Open index.html in your browser.
